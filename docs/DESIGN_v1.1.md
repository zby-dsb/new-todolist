# 每日任务清单 · 产品设计文档（v1.1）

> 状态：设计中（已与用户对齐范围，待文档确认后进入实现）
> 承接：v0.1 MVP —— 网页 UI + add/list/done/rm + 导出导入 + `tasks.json` 本地持久化

## 1. 整体方向
在 v0.1「本地单机网页 + Python 标准库零依赖 + 米色 UI」的基础上，把「每日」语义真正落地，并补充一点回顾能力：

- 仍是纯本地、不联网、不云同步；**继续零第三方依赖**。
- 本次只做轻量增强：**不做**标签/分类、提醒/通知、跨端同步（见第 4 节）。

## 2. v1.1 主要功能

### 2.1 每日视图
- 每条任务带 `date` 字段（归属日期）。
- 首页默认显示「今天」的任务；顶部提供日期导航（上一天 / 下一天 / 今天），可翻看任意历史日期。
- 新增任务**只能加到今天**；历史日期只能查看，不能往回添加。
- 过期的未完成任务**留在原日期、不顺延**，靠日期切换查看历史。

### 2.2 统计与打卡回顾
- 指标：今日完成数 / 今日总数、本周完成数、连续打卡天数、今日完成率。
- 近 7 天完成数趋势图（纯前端 SVG 绘制，零依赖）。
- 通过「统计」面板查看。

### 2.3 编辑任务内容
- 点任务文字就地编辑，回车保存 / Esc 取消；保存即更新（任务所属日期不变）。

## 3. 数据模型（`tasks.json`）
- v0.1 字段：`id` / `content` / `done` / `created_at`
- v1.1 新增：`date`（归属日期，默认创建当天）、`completed_at`（完成时记录，取消则清空）
- 兼容：旧数据缺字段时自动归一化（缺 `date` 用 `created_at` 日期；`done` 且无 `completed_at` 时用 `created_at` 近似），升级不丢数据。

## 4. 明确不做（本期）
标签 / 分类 / 优先级、提醒与通知、深色模式、拖拽排序、手机端 / 多端同步。留待后续版本。

## 5. 延续的工程约束
零第三方依赖；仅监听 `127.0.0.1`；强制 UTF-8；原子写；静态资源防路径穿越；XSS 转义；改动后提交 + 全量测试通过（遵循 AGENTS.md）。
