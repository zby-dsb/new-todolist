# 每日任务清单 · 产品设计文档（MVP）

> 版本：v0.1（MVP） ｜ 状态：设计中（已确认网页版技术栈）

## 1. 产品定位
一个轻量的个人**本地网页**待办应用，帮助用户在自己的电脑上通过浏览器记录、跟踪并完成每日任务。
MVP 阶段聚焦「最小可用闭环」，后续再迭代「每日」语义与高级能力。

## 2. 整体方向
- 网页优先，单机本地使用（不开命令行界面）
- 后端：Python 3 标准库 `http.server`，零第三方依赖
- 前端：HTML + CSS + JS 单页界面
- 数据本地持久化（`tasks.json` 文件），不联网、不云同步
- 小步快跑：先跑通核心闭环，再逐步加日期、标签、提醒等

## 3. 目标用户与使用场景
- 个人用户，习惯用浏览器、不想碰命令行
- 典型场景：每天开始前列出当日任务 → 过程中勾掉已完成项 → 随时增删；仅在本机使用

## 4. MVP 功能范围（主要功能）
以浏览器网页操作为主，后端提供对应接口：
- **add（添加）**：输入框填写任务内容 → 点「添加」
- **list（查看）**：页面列出全部任务，显示序号与状态（`[ ]` 未完成 / `[x]` 已完成），顶部统计「共 N 项 · 已完成 M 项」
- **done（完成）**：点任务前的方框勾选 / 取消
- **rm（删除）**：点任务行的「删除」按钮
- **导出 / 导入（双备份）**：导出把当前清单存成 json 文件；导入从 json 文件恢复

持久化：本地 `tasks.json` 文件，每条任务含 `id` / `内容` / `完成状态`；后端自动读写，刷新 / 关机不丢。

> 说明：MVP **不做日期 / 每日视图**，所有任务在同一个扁平清单中管理；「每日」维度留待 v1.1。

## 5. 暂不做（后续迭代）
- 日期字段、今日视图、未完成项跨天顺延
- 编辑任务内容、优先级 / 标签 / 分类
- 提醒与通知、统计与历史
- 手机端 / 多端同步（需联网后端，复杂度更高）

## 6. 技术选型
- 后端语言：Python 3，仅用标准库（`http.server` 提供接口与静态页面），不引入第三方库
- 前端：HTML + CSS + JS 单页应用（沿用 `demo/archive/index2.html` 米色界面风格）
- 存储：`tasks.json`（本地 JSON 文件），由后端读写；建议加入 `.gitignore`，避免把个人清单提交进仓库
- 结构：接口层 / 存储层 / 前端分离，便于单元测试
- 运行：本机启动小程序（提供 `http://localhost` 地址），浏览器打开即用；附启动快捷方式

- 每次改动后编写 / 更新相关测试，交付前确保所有测试通过
- MVP 测试覆盖：add / list / done / rm / 导出 / 导入 的存储与状态逻辑（单测）+ 一条接口冒烟测试

## 8. 版本路线

- **v1.1**：加入 `date`、今日视图、未完成项跨天顺延
- **v2+**：标签 / 优先级、提醒、统计、手机端 / 同步（待定）
