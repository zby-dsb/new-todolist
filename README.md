# 每日任务清单 (Daily Todo List)

> 版本：**v1.0.0 · 第一个版本** —— 项目首个可用版本。

一个本机运行的轻量级每日任务清单应用。后端仅使用 Python 3 标准库（**零第三方依赖**），
前端为原生 HTML/JS，任务数据保存在本地 `tasks.json`。

## 特性
- 任务的增删改查（CRUD）
- 本机单机运行，监听 `127.0.0.1:8000`，无需登录鉴权
- 数据以 UTF-8 原子写入本地文件，安全持久化
- 零依赖，开箱即用

## 运行方式

方式一（推荐，Windows 无黑框启动）：
双击 `start.bat`（或 `start.vbs`）。

方式二（命令行）：
```bash
python app.py
```
然后浏览器打开 http://127.0.0.1:8000/

## 目录结构
- `app.py` —— 后端服务（标准库 HTTP 服务）
- `static/` `demo/` —— 前端页面
- `docs/` —— 设计文档与使用说明
- `tests/` —— 单元测试
- `tasks.json` —— 本地数据（运行态，不纳入版本库）

仓库已通过 `.gitignore` 排除运行态文件（`tasks.json`、`app.log`、`server.pid`、`app.url` 等），
